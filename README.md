TrendVest is an investment app meant for users beginning their investment journey. 

It has a "Portfolio" page, where users can keep track of investments that they make, as well as an "Invest" page with categories "Banking", "Cars", and "Tech" that aim to display how the biggest stocks of the respective category are currently performing (tracking live data). 

The site also includes a login, giving users the opportunity to create a new account if they do not already have one.
